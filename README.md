# ClínicaLab · Práctica WISC-V

Simulador académico en español para estudiantes de Psicología Clínica de octavo semestre. Incluye 20 casos ficticios, modo estudio, examen con tiempo, explicaciones y repaso de errores. El historial se almacena únicamente en el navegador.

## Ejecutar

Abrir `dist/index.html` en un navegador. No requiere dependencias ni compilación.

## Desplegar en Vercel

Importar este repositorio con Framework Preset **Other**, sin comando de compilación y con Output Directory **dist**. La configuración está en `vercel.json`.

Revisar Deployment Protection antes de desplegar para conservar el acceso privado. Un repositorio privado no implica que la web desplegada sea privada. No desactivar protección sin autorización del propietario.

## Alcance académico

Preguntas y casos originales; no contiene reactivos ni baremos del WISC-V. No es un banco oficial del CACES, no predice aprobación y no sustituye el manual autorizado ni la supervisión profesional. La correspondencia específica con el temario vigente no se ha verificado. Las referencias se encuentran en la aplicación.
